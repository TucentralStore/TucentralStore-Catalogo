# TuCentralStore-Catalogo

Sitio: catálogo de productos de TuCentral Store, en un único archivo HTML autocontenido (`tucentral_catalogo_completo.html`), publicado por GitHub Pages.

## Enlace oficial para el cliente

Cuando el usuario pida "el enlace" o "la tienda" para enviar a sus clientes, usar siempre este (su dominio real vía GitHub Pages), NUNCA un link de Claude Artifacts:

https://tucentralstore.github.io/TucentralStore-Catalogo/tucentral_catalogo_completo.html

GitHub Pages sirve el archivo directamente desde la rama `main` del repo. Antes de confirmar que el enlace está "actualizado", verificar que la rama de trabajo esté al día con `origin/main` (o que los cambios ya se hayan fusionado/pusheado a `main`).
